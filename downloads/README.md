# Android downloads

Mixline **6.0.0** test APKs are built by GitHub Actions on every push and attached to releases for `v*` tags: open the latest **CI** run → *Artifacts* → **Mixline-APK**, or the release page. See the [README](../README.md) for installing and for keeping the signing identity across updates.

The files kept in this folder are the earlier **4.0.0-test2** and **5.0.0-test1** builds with their checksums, retained for history. A 6.0.0 build signed with a different key cannot be installed over them without uninstalling first.
