# Android testing downloads

[Download Mixline 4.0.0-test2 APK](https://github.com/Redjinal/Mixline-Mobile-DJ/raw/refs/heads/main/downloads/Mixline-4.0.0-test2.apk)

This is the signed standalone testing APK for the Samsung S26 Ultra. It uses the same package and testing certificate as test 1, so it can be installed as an update. Android may ask you to allow installation from the browser or file manager opening it.

If this repository is private, sign in to GitHub with an account that has repository access before downloading. On the APK's GitHub file page you can also choose **Download raw file**.

- Package: `com.mixline.studio.testing`
- Version: `4.0.0-test2` / `40002`
- Minimum Android: 10 (API 29)
- Target API: 36
- SHA-256: `4c5d581ee7d96490f0ed0ab7dfa085341186b4bdff153cdd2c90befab8823883`

The APK contains the bundled offline interface and original demo tracks. Live YouTube playback, S26 audio routing/latency and native file export still need phone testing. Local recordings exclude YouTube and microphone audio.

See [the device checklist](../docs/DEVICE-TESTING.md) for testing steps. Signing keys and generated development outputs remain excluded from Git; only this intentional distributable and its checksum are retained here.
