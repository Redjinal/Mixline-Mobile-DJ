# Repository guidance

Before any work, read `docs/planning/v1_0/AGENTS.md`, `docs/planning/v1_0/00_README.md` and Document 19 (`docs/planning/v1_0/sources/19_Design_Start_and_Local_First_Handoff.md`). Use requirement IDs from `docs/planning/v1_0/contracts/requirements_register.json`.

Keep `verified` distinct from `implemented`, `proposed`, `blocked` and `deferred`. Do not reuse the Mixline app in git history. Do not present fixture waveforms, meters or progress as working functionality.
